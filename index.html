Claude- · Travail par IA

Ce projet sert à apprendre à utiliser Claude Code avec GitHub. Cette page a été créée par Claude, puis proposée dans une Pull Request.

Comment cette page est arrivée ici

  1. Demande : j'ai demandé à Claude de créer une page web.
  2. Branche : Claude a travaillé sur une branche séparée, sans toucher à main.
  3. Commit : les modifications ont été enregistrées avec un message qui les décrit.
  4. Push : la branche a été envoyée sur GitHub.
  5. Pull Request : Claude a proposé d'ajouter la page à main.
  6. Merge : j'ai relu les changements et je les ai acceptés.
Prochaine étape : demander à Claude d'ajouter une nouvelle section, de changer les couleurs ou de créer une autre page.
